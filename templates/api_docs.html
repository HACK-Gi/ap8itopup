📚 របៀបប្រើ API

ដើម្បីបញ្ជាទិញដោយស្វ័យប្រវត្តិ សូមប្រើ API Key របស់អ្នក។

1. យក API Key

ចូលទៅកាន់ Dashboard ហើយចុច "បង្កើត API Key"។

2. Endpoint
POST {{ request.host_url }}api/order
3. Headers
Authorization: YOUR_API_KEY
Content-Type: application/json
4. Body (JSON)
{
  "game": "mlbb_ph",
  "product": "50x2PH",
  "uid": "123456789",
  "server_id": "11345"
}

server_id គឺចាំបាច់សម្រាប់ហ្គេមដែលត្រូវការ។

5. ឧទាហរណ៍ curl
curl -X POST {{ request.host_url }}api/order \
  -H "Authorization: api_sk_xxxx" \
  -H "Content-Type: application/json" \
  -d '{"game":"hok","product":"16","uid":"123456"}'
6. Response ពេលជោគជ័យ
{
  "status": "success",
  "order_id": 5,
  "command": "/hok 123456 16"
}
